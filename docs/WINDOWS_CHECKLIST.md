# Чек-лист приёмки на Windows

Прогнать после получения проекта. Время: ~15 минут. Всё, что отмечено ⛳, — обязательные пункты ТЗ.

## 0. Подготовка
- [ ] Node.js 20+: `node -v`
- [ ] Каталоги рядом: `C:\dev\clair-gateway` и `C:\dev\clair-pro` (пути — пример)
- [ ] CLAIR Base на месте: `C:\Clair_pilot\` существует, `dist\` внутри

## 1. Установка
```bat
cd C:\dev\clair-pro
npm install
npm install --prefix C:\dev\clair-gateway
```
- [ ] обе установки прошли без ошибок

## 2. ⛳ Старт одной командой (реальный Base)
```bat
set CLAIR_PILOT_DIR=C:\Clair_pilot
set CLAIR_GATEWAY_DIR=C:\dev\clair-gateway
clair-pro.bat
```
- [ ] в консоли: `[clair-base] готов`, `[gateway] готов`, `[dashboard] готов`
- [ ] браузер открылся сам на `http://127.0.0.1:4000`
- [ ] KPI-карточки отрисованы (даже если «0»)

## 3. ⛳ Health checks всех трёх сервисов
```bat
curl http://127.0.0.1:3000/health
curl http://127.0.0.1:8080/health
curl http://127.0.0.1:4000/health
```
- [ ] три ответа `{"status":"ok",...}`

## 4. ⛳ Графики на реальных данных
- [ ] на дашборде есть данные (если пусто — шаг 5 сначала, потом вернуться)
- [ ] 4 графика отрисованы: экономия, сессии, кэш, задержка
- [ ] переключение фильтров (сессия/кэш/поиск) обновляет таблицу

## 5. ⛳ Тестовый запрос через UI
- [ ] в поле «Тестовый запрос» — дефолтный текст, кнопка «Отправить ▸»
- [ ] появился «Ответ LLM» и чипы метрик (сэкономлено/коэф./кэш/мс)
- [ ] новая строка появилась в таблице (SSE, ~1-2 с, без F5)

## 6. Повторный запрос → кэш
- [ ] отправить тот же текст второй раз: в чипах `кэш: HIT` (TTL 5 мин)
- [ ] в таблице у новой записи КЭШ = HIT

## 7. ⛳ Экспорт
- [ ] кнопка CSV скачивает файл; в нём заголовок и строки (открывается в Excel)
- [ ] кнопка JSON скачивает файл со счётчиком `count` и массивом `entries`

## 8. Темы и адаптивность
- [ ] кнопка 🌙/☀️ переключает тёмную/светлую тему; выбор сохраняется после F5
- [ ] (опционально) сузить окно до ~700 px: layout перестраивается в одну колонку

## 9. ⛳ Graceful shutdown
- [ ] в консоли launcher нажать `Ctrl+C`
- [ ] все три тега пишут завершение, консоль возвращается в prompt
- [ ] повторный `curl http://127.0.0.1:8080/health` — отказ в соединении (нет зомби)
- [ ] повторный запуск `clair-pro.bat` работает штатно

## 10. Демо-режим (без Base и интернета)
```bat
clair-pro.bat --demo
```
- [ ] mock Base + mock LLM поднялись; полный цикл в UI работает
- [ ] `Ctrl+C` гасит всё

## 11. Docker (опционально)
```bat
copy .env.example .env
docker compose up --build
```
- [ ] все 3 контейнера healthy (`docker compose ps`)
- [ ] http://localhost:4000 показывает дашборд
- ⚠️ Если `c:\Clair_pilot` не монтируется — зафиксировать симптом, использовать Node-лаунчер (это не блокер).

## 12. ⛳ CLAIR Base не изменён
```bat
cd C:\Clair_pilot
git status
```
- [ ] ни одного изменения / нового файла (или каталог вне git-надзора — проверить даты изменения)
- [ ] лог `logs\clair_pilot.log.jsonl` — только дописывался самим Base

Фидбек по каждому пункту (ок / symptom / скриншот) — в чат.
